# Glow Tiles

Неоновая музыкальная игра в духе PianoGlow / Piano Tiles. Работает прямо в браузере, на телефоне и на компьютере. Это один файл `index.html` без зависимостей.

## Как играть

- Нажимай на светящиеся плитки снизу вверх, и из нажатий сложится мелодия.
- Длинные плитки с кружком нужно удерживать, пока они не заполнятся светом.
- Если пропустишь плитку или нажмёшь на пустую дорожку, игра закончится.
- После каждого пройденного круга мелодии даётся звезда, а скорость растёт.
- Клавиатура: `D` `F` `J` `K` (или `1`–`4`). `Esc`/`P` ставит паузу, `Space`/`Enter` запускает заново.

## Запуск

Открой `glow-tiles/index.html` в браузере. Можно также опубликовать через GitHub Pages.

## Устройство

- Графика рисуется на Canvas 2D: плитки с неоновым свечением, частицы, вспышки дорожек, цвет меняется с каждым кругом.
- Звук синтезируется через Web Audio (аддитивный «пианинный» тембр и эхо), аудиофайлы не нужны.
- Рекорды хранятся в `localStorage`.
- Мелодии записаны строками нот в массиве `SONGS`: `E5` — нота, `A4+A2` — аккорд, `:2` — длинная плитка. Чтобы добавить песню, допиши новый объект в этот массив.

Все мелодии в игре находятся в общественном достоянии. Код, графика и звук написаны с нуля. Ассеты и треки PianoGlow не используются.
