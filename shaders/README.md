# Шейдеры

Автономные полноэкранные WebGL-сцены: один самодостаточный HTML-файл на сцену, без интерфейса. Открываются прямо из файла.

1. [Гаргантюа](01-gargantua.html) — чёрная дыра Шварцшильда: изгиб лучей (интегратор Верле), объёмный волокнистый диск, допплер (слева ярче и белее, справа тусклый красный), кольцо фотонов 1px, экспоненциальный bloom, анаморфный блик, звёзды с отклонением.

Служебный параметр `?still=<сек>` рисует один кадр без анимации, `?scale=<0.35..1>` фиксирует разрешение сцены (по умолчанию оно подстраивается под 60 FPS).
