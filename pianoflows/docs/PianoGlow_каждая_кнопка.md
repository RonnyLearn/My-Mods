# PianoGlow 0.50.0 — справочник по каждой кнопке и ползунку

*Как составлено: прошёл интерфейс вживую, распаковал код новой версии 0.50.0 и расшифровал из него полную схему настроек (≈660 параметров: значение по умолчанию, минимум, максимум, шаг, варианты и официальная подсказка разработчика). Названия элементов даны так, как они написаны в английском интерфейсе, рядом — перевод.*

**Как читать таблицы.** «По умолч.» — заводское значение (не обязательно то, что стоит у тебя сейчас). Любой ползунок и переключатель можно сбросить к заводскому значению **правой кнопкой мыши** по нему (на телефоне — долгим нажатием). Строка поиска «Search settings…» наверху панели ищет по всем вкладкам сразу. Значок замка означает функцию платной версии.

Пометки: **[ПК]** — работает только в скачанной версии для компьютера; **[₽]** — нужна платная (Full) версия; **[устр.]** — хранится только на этом компьютере и не синхронизируется с аккаунтом.

## 1.3. Нижняя панель (над клавишами)

| Элемент | Что делает |
|---|---|
| **Soft** | Индикатор/кнопка левой педали (приглушение). Пока она зажата, сила живых нот умножается на «Soft Pedal Multiplier». По умолчанию скрыт. |
| **Sostenuto** | Средняя педаль: удерживает только те ноты, которые были зажаты в момент нажатия педали. По умолчанию скрыт. |
| **Sustain** | Индикатор правой педали (горит, когда нажата). |
| **NORMAL / INVERT / TOGGLE** | Режим педали на пробеле: держать = педаль / педаль всегда нажата, пробел отпускает / пробел включает-выключает. Клик переключает, клавиша ' (апостроф) тоже. |
| **− 0 +** | Транспозиция в полутонах (−24…+24). |
| **Значок метронома + число** | BPM метронома; 0 = выключен (0…600). Щёлкает высоким и низким звуком по очереди. |
| **SHIFT LOCK** | Надпись появляется, когда включён Shift Lock. |

Чуть выше — **статистика «Today / Lifetime»**: три строки (клавиатура QWERTY, MIDI-пианино, игровые очки), у каждой счётчик нот/очков и активное время игры за сегодня и за всё время. Справа внизу — **нотоносец** (показывает нажатые ноты на скрипичном и басовом ключе), над статистикой — **определитель аккордов** (называет интервал или аккорд, который ты держишь).

### Ear Interval — интервалы на слух
Звучат две ноты — выбери интервал. Интервалы, где ошибаешься чаще, выпадают чаще; при игре двух нот интервал подписывается автоматически. Настройки: **Min Interval** (−3, от −24; минус = нисходящий), **Max Interval** (3, до 24), **Absolute Pitch Mode** (звучит одна нота без опоры — назови точную ноту и октаву), звуки.

### Ear Chords — аккорды на слух
Звучит аккорд — определи тип и обращение. **Chord Types** (по умолч. мажор и минор), **Chord Inversions** (0 — основной вид, 1 — первое обращение…), **Random Root** (случайная тоника вместо до первой октавы), звуки.

### Chords — сыграть аккорд
Показывается символ — сыграй аккорд (самая нижняя нота должна быть басом, остальные в любом порядке). **Chord Types**: maj, m, dim, aug, maj7, m7, 7, dim7, m(maj7), m7b5, aug(maj7) и др.; **Inversions**: Root / 1st / 2nd / 3rd; **Notation**: Chord Names / Roman (Major) / Roman (Minor) + **Key Center** (тоника для римских цифр); **Random Root** (вкл); **Show Piano Hint** (подсветка аппликатуры аккорда; если выключено — видно при наведении или с педалью).

### Rhythm — ритм
Слушаешь рисунок и повторяешь пробелом или любой MIDI-нотой. **Rhythm Note Values**: целая, половинная с точкой, половинная, четверть с точкой, четверть, восьмая, триоль восьмых, шестнадцатая (по умолч. четверть + восьмая). **Rhythm Rest Values**: паузы (по умолч. без пауз). **Rhythm BPM** (100, 40–240), **Time Signature** (2/4, 3/4, 4/4, 5/4, 6/4), **Beat Guide** — громкость хай-хэта на каждую долю (100 %, 0–200), **Tap Sound** — громкость нажатий (100 %).

### Love — игра для двоих
Один играет на пианино, второй наводит курсор (или кликает — **Love Input Mode**: hover / click) на его нотные лучи и набирает очки.

### Asteroids — астероиды
На пианино летят астероиды с последовательностями нот. Сыграй первую ноту — захватишь цель, доиграй последовательность — взрыв. Счёт: Score, Streak, Best, Prev, Accuracy, **Destroyed**, **Misses**, **Skips**. Настройки: **Speed** (20, 10–80), **Frequency** — астероидов в минуту (15, 5–40), **Accidentals**: None / # / b / All, звуки Score / Miss / **Explode SFX**.
