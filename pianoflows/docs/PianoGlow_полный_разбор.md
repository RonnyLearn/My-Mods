*Составлено по установленной у тебя версии 0.37.0 (Steam, D:\steam\steamapps\common\pianoglow): интерфейс пройден вживую, плюс распакован исходный код (app.asar), встроенный русский перевод и файл сохранённых настроек.*

## 1. Суть приложения

**PianoGlow** — это «виртуальное пианино + ритм-игра + тренажёр + социальная сеть пианистов» с неоновой 3D-графикой. Слоган разработчика: *Multiplayer piano with training, leaderboards & neon visuals* («Мультиплеерное пианино с тренировками, таблицами лидеров и неоновыми визуалами»).

Основная идея — одно приложение закрывает всё, что нужно человеку, играющему на пианино:

1. **Играть**: на цифровом пианино (MIDI по USB-B или Bluetooth), на клавиатуре компьютера (QWERTY, раскладка как в пианино-играх Roblox) или мышкой. Над клавишами вылетают светящиеся «нотные лучи».
2. **Учиться**: падающие ноты (как в Synthesia), тренажёр чтения нот, слух (интервалы и аккорды), ритм, аккорды, гаммы и арпеджио, QWERTY-набор.
3. **Находить музыку**: встроенная библиотека на 50 000+ QWERTY-нот, библиотека MusicXML, локальная папка, Steam Workshop, ИИ-перевод аудио в MIDI.
4. **Создавать контент**: запись MIDI/аудио/видео, рендер красивых видео из MIDI для TikTok/YouTube, MIDI-редактор, лупер.
5. **Общаться**: мультиплеерные комнаты (играете по очереди или все сразу), глобальный чат, личные сообщения, друзья, профили, мини-игры для двоих.
6. **Геймификация**: монеты, самоцветы, ежедневные награды и задания, серии, магазин косметики, статистика, таблица лидеров.

Разработчик — **TheAlanski** (основатель и программист), менеджмент/советник — **noakopiano**, тестер/стример — **7vlw**. Поддержка: support@pianoglow.com, Discord: discord.gg/pianoglow. Платформы: Windows, macOS, Linux, iOS, Android, браузер (pianoglow.com, бета, отдельный мультиплеер), активность Discord.

## 2. Как устроено технически

| Что | Чем сделано |
|---|---|
| Оболочка | Electron (веб-приложение внутри Chromium), основной процесс скомпилирован в байткод (bytenode), чтобы его было трудно читать |
| Графика | Three.js (WebGL, 3D-пианино, шейдеры лучей, частицы) |
| Синтезатор | SpessaSynth (воспроизведение SoundFont .sf2/.sf3 с эффектами реверберации, хоруса и задержки в стиле Roland GS) |
| Вывод звука | собственный модуль на miniaudio (драйверы WASAPI и ASIO для малой задержки) |
| Нотная запись | OpenSheetMusicDisplay и VexFlow (рисуют ноты), jsPDF (экспорт в PDF) |
| Распознавание текста | PaddleOCR и Tesseract (читают QWERTY-ноты с картинок и PDF) |
| ИИ | ONNX Runtime (нейросети в приложении), отдельный t.exe на 138 МБ — вероятно, модель транскрипции аудио в MIDI |
| Видео | ffmpeg.exe (сборка MP4), кодирование через WebCodecs |
| Сеть | Socket.IO (чат, комнаты), P2P-соединения для MIDI и голоса |
| Steam | steamworks.js (вход, покупки, Workshop, время игры) |
| Bluetooth MIDI | отдельная утилита BluetoothMidiBroker.exe |
| VST3 | отдельные рабочие процессы для загрузки плагинов |

Обновления: при запуске приложение сверяет версию с сервером. **Сейчас у тебя 0.37.0, а сервер требует 0.50.0**, поэтому онлайн-функции (вход, мультиплеер, магазин, профиль, отправка в чат) отключены: в чате написано «Update to v0.50.0 to chat». Лечится обновлением через Steam (или перезапуском, если обновление уже скачано). Офлайн всё остальное работает.

Настройки хранятся локально (%APPDATA%\pianoglow) и синхронизируются с аккаунтом. Есть файл восстановления настроек и до 10 пресетов.

## 3. Главный экран

**Внизу** — пианино (3D или плоское) со светящейся линией-границей. На клавишах — подписи (QWERTY-буквы или названия нот).

**Над пианино слева** — нижняя панель: кнопки педалей Soft / Sostenuto / Sustain и режим сустейна (NORMAL / INVERT / TOGGLE), транспозиция (− 0 +), метроном (BPM). Выше — **статистика «Сегодня / За всё время»**: отдельные строки для QWERTY-нот, MIDI-нот и игровых очков, у каждой счётчик и активное время игры.

**Справа внизу** — нотоносец (скрипичный и басовый ключ), на нём в реальном времени рисуются нажатые ноты. Над статистикой может быть определитель аккордов и интервалов.

**Справа вверху** — окно **глобального чата**.

## 4. Ввод: чем можно играть

### 4.1. Клавиатура компьютера (QWERTY)
- Раскладка по умолчанию совпадает с виртуальными пианино и пианино-играми Roblox: цифры и буквы — белые клавиши, с Shift — диезы (чёрные клавиши), с CTRL — дополнительные ноты за краями основного диапазона.
- Раскладки: QWERTY, QWERTZ, AZERTY, «Minor», «Phrygian Dominant» (ладовые), плюс **свои раскладки** («+ New Custom Layout»).
- Автоконвертация QWERTY-нот и подписей под текущую раскладку; отдельная галочка для кириллицы (ЙЦУКЕН).
- **Помощник Shift/CTRL**: «Shift на следующую клавишу» (Shift + клавиша без ноты играет на полутон выше), для блокнота и режима набора можно включить «использовать Shift/CTRL-версию при необходимости» или «игнорировать Shift/CTRL».
- **Динамика (сила нажатия)** — у клавиатуры её нет, поэтому она вычисляется:
  - *Random* — случайно в заданном диапазоне;
  - *Predictive* — по скорости набора (быстрее печатаешь — громче), диапазон по умолчанию 64–127;
  - кривая переназначения (Linear / Soft / Hard / своя), **кривая по высоте** (Flat / Fall / Rise / Scoop — например, басы тише), множитель громкости и горячие клавиши ALT+1…0 для множителя 0.1…1.0.
- «Sustain Repedal Assist» — помощь с перенажатием педали для QWERTY.
- Можно полностью отключить ввод с клавиатуры.

### 4.2. MIDI-пианино
- Подключение по USB-B или Bluetooth (кнопка «Pair Bluetooth MIDI»). У тебя подключены SE61 и MIDIIN2 (SE61).
- Для каждого входа — вкл/выкл, своя кривая динамики.
- **MIDI-выход**: режим «Light Up» — подсвечивает клавиши на пианино с подсветкой.
- Инверсия педали (для «перевёрнутых» педалей), помощь с перенажатием педали.
- **Type using MIDI** — печатать текст с пианино (для режима набора слов).
- MIDI-монитор (в «Ещё») — показывает сырые MIDI-сообщения (байты, каналы, порты).

### 4.3. Мышь
Клик по клавише; динамика зависит от места клика («громче ближе к низу клавиши»), диапазон 64–127, есть подсказка с текущей динамикой.

### 4.4. Wooting (аналоговые клавиатуры)
Настоящая динамика от глубины нажатия через WebHID: порог срабатывания (37.6 %), масштаб динамики (5.0×), минимальная динамика (35).

### 4.5. Педаль сустейна на пробеле (QWERTY)
- **Normal** — держишь пробел, педаль нажата.
- **Invert** — педаль всегда нажата, пробел её отпускает (у тебя включён этот режим).
- **Toggle** — пробел включает/выключает.
Горячая клавиша циклически переключает разрешённые режимы.

### 4.6. Транспозиция
Сдвиг на полутоны и октавы горячими клавишами. **True Transpose** («истинная транспозиция»): сдвигается сама нота, а не только звук (C с +3 будет считаться D#), по желанию это отражается и на подписях.

## 5. Звук

### 5.1. SoundFont (F6)
- **Встроенные звуки (59)** по категориям Piano, Wind, String, Voice, Drums, Funny, Percussion, Other, плюс Favorites и Custom. Среди них: Yamaha Grand Lite, Acoustic Grand, Fantasy Piano, E.Piano 1/2, Honky Tonk, органы, струнные, духовые, хоры, синтезаторы, ударные и «весёлые» (Meow, Dog, Quack, Keyboard Cat, Boing, Monkey, Moof, Sosumi, Wild Eep и т.п.).
- **Свои SoundFont**: загрузить файл или указать папку (у тебя D:\PianoGlow SF2 — там Dora Marks Fazioli, Nice-Keys-Ultimate, Abbey Steinway и др.), избранное, сортировка, выбор пресета внутри .sf2 (bankMSB:bankLSB:program).
- **Слои**: несколько SoundFont одновременно, у каждого свой диапазон клавиш и громкость. Режимы Split (основной внизу, второй вверху, с точкой разделения и зоной перекрытия) и Layer (оба на всех клавишах).
- **Create .sf2** — конструктор SoundFont: перетаскиваешь аудиосэмплы, высота определяется из имени файла, можно интерполировать на все 88 клавиш. Есть сжатие .sf2.
- **Load VST3** (только Steam-версия): плагины-эффекты (накладываются на SoundFont) или плагины-инструменты (заменяют SoundFont), с собственным окном интерфейса.

### 5.2. Настройки звука
- **Качество и задержка**: буфер (Best Latency / Balanced / Best Quality), лимит голосов (до 1000), частота дискретизации (Auto, 22, 44.1, 48 кГц), интерполяция (Best — кубическая, Normal — линейная, Poor), размер буфера VST, драйвер WASAPI/ASIO, выбор устройства вывода.
- **Громкости**: Master (до 200 %), MIDI, QWERTY, Playback, другие игроки, SFX, метроном, своё пианино в мультиплеере.
- **Реверберация**: пресеты-«помещения» *Backrooms, School Bathrooms, Mom's Basement, Concert Hall, Inside a Whale, Liminal Pool* (+ космос), либо альтернативная реверберация SpessaSynth (Room 1–3, Hall 1–2, Plate, Delay, Panning Delay) с подробными ручками.
- **Хорус**: Chorus 1–4, Feedback Chorus, Flanger, Short Delay и др. **Задержка (эхо)**: Delay 1–4, Pan Delay 1–4, Dly To Rev, Pan Repeat.
- **Эквалайзер**: Flat, Warm, Bright, Bass Boost, Scooped + 3 полосы.
- **Разное**: множитель затухания после отпускания, макс. длина сустейна (30 с), инверсия высоты (пианино «вверх ногами»), строй A4 (440 Гц).
- **Эмбиент** — фоновый звук: ветер, птицы, винил, дождь.

### 6.5. Интерфейс
Масштаб интерфейса; видимость каждой кнопки верхней панели («всегда» / «при движении мыши»); поверх всех окон; чат вкл/выкл; каждый элемент нижней панели (Вкл / Выкл / При движении мыши); экранная клавиатура на мобильных; размер круглых всплывающих окон громкости и транспозиции; вертикальные направляющие линии между B–C и E–F.

### 6.6. Система

## 7. Библиотека музыки (F1)

1. **QWERTY Library** — 50 000+ QWERTY-нот (из Trello-досок сообщества и vp-sheets.arijan.dev). У каждой песни: **уровень сложности** (считается по среднему размеру аккорда и доле Shift/CTRL-нот), средний размер аккорда, процент Shift. Фильтр по сложности, сортировка (популярность, недавние/избранное, по сложности, по Shift %, CTRL %, размеру аккорда). Открыть в режиме **Typing**, **Notepad** или **Word**.
2. **MusicXML Library** — ноты с падающими нотами и практикой, для настоящего пианино (встроено 148 композиций: поп, аниме, классика). Метка сложности Easy / Medium, тональность. Открыть в Falling Notes, Player, Queue, Word.
3. **Local Folder** — сканирует твою папку (до 4 уровней вложенности) на MIDI и MusicXML.
4. **Steam Workshop** — подписки на QWERTY-ноты и MIDI сообщества, публикация своих (название, описание, сложность, подтверждение прав).

## 8. Плеер (F4): воспроизведение, практика, редактор

Загружаешь MIDI или MusicXML (или папку в очередь). Три вкладки:

**Playback (просмотр)**: play/stop, перемотка, скорость, вступление (задержка перед началом), очередь с повтором (очередь / песня / без повтора) и перемешиванием, 2D-ноты и 3D-ноты поверх экрана с кинематографической камерой, «подогнать ноты под клавиатуру», авто-панорама и зум, включение пианино и лучей, **дорожки** (каждую вкл/выкл, пометка левой/правой руки), цвета рук. Кнопки: **Save WAV**, **Render Video**, **Audio Override** (подложить свою аудиодорожку), **MIDI→QWERTY** (конвертация в QWERTY-ноты), **Simplify** (упростить), **Fingering** (ИИ-аппликатура, бета: номера пальцев 1–5 по анатомии руки), **Generate PDF** (ноты в PDF), экспорт MusicXML.

**Practice (практика, как Synthesia)**: ноты падают, нажимаешь их вовремя; очки, серия, лучший результат, ошибки. У каждой дорожки режим ON (играешь сам) / AUTO (играет программа) / OFF. **Петли** (начало/конец, сохранение как пресет), **тепловая карта** ошибок, скорость, «авто-удержание и педаль», режим паузы (всегда ждать нажатия / пауза один раз / никогда), цвета рук и чёрных клавиш, показ нот и падающих нот.

**Editor (MIDI-редактор)**: инструменты Select (S), Draw (D), Erase (E), Pedal (P); привязка к сетке, темп и тональность, запись живого ввода в ноты, длина ноты по умолчанию, дорожки (добавить, переместить/разделить, слить), масштаб, отмена/повтор, автосохранение с восстановлением.

**Fit to keyboard** («подогнать под клавиатуру»): перестраивает MIDI под меньшее количество клавиш (например, 61), сохраняя мелодию, аккорды и разделение рук.

## 9. Игровые режимы (F2) — 11 штук

| Режим | Механика |
|---|---|
| **Falling Notes** | Загружаешь MIDI/MusicXML, нажимаешь падающие ноты у нижней линии (та же «Практика» из плеера). |
| **QWERTY Typing** | Вставляешь QWERTY-ноты и нажимаешь клавиши по порядку, как в клавиатурном тренажёре. Ритма нет, считаются очки и серии. Нотная запись и падающие ноты генерируются автоматически. «Помощь с аккордами»: 0 — выкл, 1 — остаток аккорда доигрывается после любой одной ноты, 2 — после двух. Клавиши [ и ] — автопроигрывание следующих нот. |
| **Sheet Music Trainer** | Бесконечные случайные ноты на нотоносце, нажимаешь правильную клавишу. Ключ (скрипичный / басовый / оба), тональность, диапазон (Beginner, Normal, Expert, Low/High Ledgers — добавочные линии, Custom), плотность (одиночные, редкие, лёгкие, аккорды, своя), знаки альтерации, подсказки (подсветка клавиш, названия нот после ошибки). |
| **Ear Interval** | Звучат две ноты — определи интервал. Интервалы, в которых чаще ошибаешься, выпадают чаще. |
| **Ear Chords** | Звучит аккорд — определи тип и обращение (случайная тоника по желанию). |
| **Chords** | Показывается символ аккорда — сыграй его. Типы: maj, m, dim, aug, maj7, m7, 7, dim7, m(maj7), m7b5 и др.; обращения; запись названиями или римскими цифрами (мажор/минор); подсказка на клавишах. |
| **Rhythm** | Слушаешь ритмический рисунок и повторяешь пробелом или MIDI-нотой. Выбор длительностей нот и пауз, BPM, размер такта. |
| **Love** | Для двоих: один играет, другой наводит курсор или кликает по его нотным лучам и получает очки. |
| **Asteroids** | На пианино падают астероиды с последовательностями нот; сыграй первую ноту, чтобы захватить цель, потом доиграй последовательность. Скорость, частота, знаки альтерации. |
| **Scales & Arpeggios** | Гаммы (мажор, 3 вида минора, пентатоники, блюз, хроматика), арпеджио, септаккорды; выбор тоник, рук (левая / правая / обе / в противоходе), направления, 1–3 октав, аппликатуры (эргономичная / непрерывная), повторов и порядка. Пресеты Beginner / Intermediate / Advanced / Expert. |
| **Word Typing** | Набор обычных слов на время (30 с, топ-200 слов) — можно даже с пианино! Каждый символ может играть аккорд из выбранной песни (QWERTY или MusicXML), считаются WPM и CPM, слабые слова выпадают чаще. |

В мультиплеерной комнате доступны только Falling Notes, QWERTY Typing и Word Typing.

## 10. Блокнот (F7)

Текстовый редактор для QWERTY-нот (формат: буквы — ноты, `[ ]` — аккорды, пробелы — паузы):
- **Автоплеер** с BPM (слушать ноты), пошаговое полуавтоматическое воспроизведение;
- **Adjust Transpose**: Optimal (подобрать сдвиг, чтобы было меньше Shift/CTRL), −1 / +1, **Simplify** (упростить аккорды до N нот);
- счётчики Shift и CTRL-нот, пропуск разделителей, индикаторы транспонирования;
- копировать, вставить, открыть, сохранить, очистить, разбивка на страницы, размер шрифта;
- «Open in QWERTY Typing» и «Open in Word Typing».

## 11. Запись (F5)

- **MIDI-запись** идёт **всегда в фоне** и сама ставится на паузу после 60 секунд бездействия. Save MIDI (Alt+Q), Clear.
- **Audio Capture** — запись звука.
- **Render Video** — рендер видео из MIDI/MusicXML (FPS, разрешение, наложение 2D-нот) через ffmpeg: высокое качество, не зависит от производительности.
- **Record Video** (Alt+W) — захват экрана в реальном времени (качество ниже, чем у рендера), с интерфейсом или без.
- **Скриншоты** (Alt+E), в буфер или в файл.
- **Submit Social Media Content** — отправь ролик с PianoGlow (слово «PianoGlow» в названии) из TikTok, Instagram или YouTube и получи **100 000 монет и 2 000 самоцветов** (раз в 24 часа на каждую площадку).

Встроенное руководство по видео советует накладывать рендер на съёмку рук в режиме наложения Add/Screen (After Effects, CapCut) и использовать 3D Camera Tracking.

## 12. «Ещё» (F10) и прочие окна

- **Circle of Fifths** — интерактивный квинтовый круг.
- **Webcam** — окно веб-камеры (можно поставить за лучи — для стримов).
- **Video Player** — локальное видео поверх приложения (с зацикливанием).
- **AI Convert To MIDI** — ИИ переводит аудио (wav, mp3, flac, ogg, m4a) в MIDI за несколько минут. Только Steam-версия.
- **MIDI Editor**, **MIDI Monitor**.
- **MIDI Looper** — записываешь петлю (темп, длина в тактах, квантизация), она крутится, а ты играешь поверх.
- **Pitch & Modulation** — питч-бенд и модуляция (вибрато) с колёс MIDI-клавиатуры или с назначенных клавиш; диапазон бенда, скорость.
- **Web Browser** — встроенный браузер (с предупреждением о недоверенных сайтах).
- **Ideas Forum** — предложения и голосования вместе с Discord-сообществом.
- **Report Bug** — отчёт об ошибке с логами.
- **PDF & Image Viewer (F8)** — открыть PDF или картинку с нотами; есть **OCR**: распознаёт QWERTY-ноты с изображения и позволяет их проиграть.

## 13. Онлайн и соцчасть (нужен вход)

**Аккаунт**: вход через Steam, Discord, Google или Apple. Профиль: имя пользователя (ссылка pianoglow.com/@имя, менять раз в 30 дней), отображаемое имя, био (до 200 символов), флаг страны, привязка TikTok, Instagram, YouTube (проверяется по ссылке в био, показывается число подписчиков), видимость профиля и статуса онлайн, активность в Discord.

**Чат**:
- **Global Chat** — общий чат, *писать могут только владельцы платной версии* (также он связан с каналом #cross-chat в Discord).
- **Room Chat** — чат комнаты, бесплатно для всех.
- **Личные сообщения**: хранятся 90 дней, реакции, редактирование, спам-папка, «кто может писать» (все / подписки / никто), блокировка, заглушение, автоперевод.
- Эмодзи, GIF и стикеры (через KLIPY).

**Социальное**: подписки и подписчики (взаимная подписка = друг), уведомления, жалобы на людей и сообщения (оскорбления, NSFW, мошенничество…), модерация с банами чата, игр и Workshop.

**Мультиплеер (F3)**:
- Живые комнаты: название, пароль (или публичная), вместимость 4–30 игроков, зрители.
- **Режим очереди**: игроки играют по очереди, время на ход 15 с – 10 мин, «завершить ход», очередь, автоматический возврат после хода. Либо **FFA** (свободный режим — все сразу).
- Хост: кик, передача хоста, настройки комнаты, бан на вход. **Голосование за кик** (не чаще раза в 30 минут, хоста кикнуть нельзя).
- **Love Game** в комнате: кликай или наводи курсор на ноты других игроков — получаешь очки.
- **Чаевые** — перевод монет другому игроку (с комиссией).
- Видны курсоры других игроков и (по желанию) их темы; можно слышать их свои SoundFont, VST и петли.
- Технически: P2P для MIDI-событий (меньше задержка), буфер джиттера (50 мс), пинг до сервера в Германии, **голосовой чат** в комнатах.

**Статистика (F9)**: профиль (QWERTY и MIDI нажатия, время игры, игровой счёт, отправленные и полученные чаевые, серии, выполненные задания, календарь активности), **таблица лидеров**, статистика по клавишам на всех устройствах.

## 14. Экономика

**Две валюты**: монеты (зарабатываются) и **самоцветы** (покупаются за реальные деньги в Steam или даются наградами).

Как получить:
- **Daily** — ежедневная награда: база + **бонус серии +10 монет за каждый день подряд (без ограничения)**; сброс в полночь по твоему времени; есть механика «пропуск дня» для серии (точные условия задаёт сервер, офлайн их не проверить).
- **Ежедневное задание** — сыграть 15 минут (время QWERTY + MIDI или время в игре, что больше), награда равна бонусу серии; своя серия заданий.
- **Самоцветы за часы в Steam**: «{N} самоцветов / час» — забираются за накопленное время игры при запуске через Steam.
- **Ролик в соцсетях**: 100 000 монет + 2 000 самоцветов.
- Праздничные награды: **День фортепиано 29 марта** (88-й день года — по одному на клавишу), **1 апреля** (шуточная «награда пианиста месяца» + настоящий подарок), бонус за поддержку в раннем доступе.

## 16. Горячие клавиши (по умолчанию)

| Действие | Клавиша |
|---|---|
| Громче / тише | Ins / Del |
| Перейти в чат | Enter |
| Страница вверх / вниз (блокнот) | PgUp / PgDn |
| Транспозиция +1 / −1 | ↑ / ↓ |
| Транспозиция +12 / −12 (октава) | → / ← |
| Сброс транспозиции | Alt+↑ |
| Транспозиция «удерживать + ввести число», отмена транспозиции | значок Tab / Tab+Backspace |
| Разделы (настройки, библиотека… помощь) | Esc, F1–F11 |
| Практика: вперёд к следующей группе нот | [ или ] |
| Практика: к началу петли | Alt+F1 |
| MIDI-редактор: выделить / рисовать / стереть / педаль | S / D / E / P |
| Сохранить MIDI | Alt+Q |
| Записать видео | Alt+W |
| Скриншот | Alt+E |
| Множитель громкости QWERTY (если включено) | Alt+1…Alt+0 |

Ещё можно назначить: Shift Lock, soft pedal, sostenuto, питч-бенд вверх/вниз, модуляцию, переключение режима сустейна. Колесо мыши перематывает в плеере, практике, редакторе и QWERTY-наборе.
